    Limb dimensions · millimeters
    Motors & gearing
    Angles are measured from joint neutral. Higher gear ratios reduce output speed and servo travel. Pin 8 controls the gripper.
    Applied settings are saved in this browser.
    

    Motor profiles change limits, speed, step resolution, and shoulder/elbow housing size. This is a kinematic model; torque and electronics are not simulated. Objects use simplified collision shapes and gravity.
    

    

    Sketch reference
    

    Write an Arduino sketch with void setup() and void loop(). Setup runs once; loop repeats until Stop. Ctrl/Cmd+Enter runs your sketch.
    

    This browser interprets a supported Arduino/C++ subset. It does not compile AVR firmware or run arbitrary Arduino libraries.
    

    Servo.h
    #include <Servo.h>
Servo base;
void setup() { base.attach(2); }
void loop() {
  base.write(120);
  delay(500);
  base.write(60);
  delay(500);
}
    Default pins 2–7 map to J1–J6. Remap them in Build arm. Servo.write accepts 0–180°; 90° is joint neutral. Motor and mechanical limits still apply. Pin 8: below 90 closes the gripper, 90 or above opens it. Servo cannot drive stepper axes; use Axis commands.
    

    Axis.h · simulator library
    Arm.moveL(x,y,z,ms) plans a straight tool line. Arm.movePose(x,y,z,roll,pitch,yaw,ms) requests world XYZ Euler orientation in degrees. All position values are millimeters. Every intermediate pose must respect reach and joint limits.
    Sensor expressions: Arm.isHolding(), Arm.objectCount(), Arm.x(), Arm.y(), Arm.z() and Arm.joint(1). These read the simulator, not a physical controller.
    Arm.moveJ(j1, j2, j3, j4, j5, j6, ms)
    Move joints in degrees from neutral. Duration is optional (1000 ms). Motor speed can extend it.
    Arm.moveTo(x, y, z, ms)
    Position the tool in millimeters using inverse kinematics. Y points up; custom dimensions and limits change reach.
    Arm.grip(); Arm.release(); Arm.home();
    Grab a nearby object, release, or move to the current build's home pose.
    delay(ms); Serial.println("Hello");
    Wait 0–30000 ms or print to the console. Serial.begin is accepted.
    

    Supported: scalar declarations, fixed arrays, user functions, if/else, for/while, break/continue/return, arithmetic, comparisons, bool, Serial, millis, common math helpers, Servo attach/write/read/detach/attached. Numbers use browser numeric arithmetic; AVR integer overflow and precise hardware timing are not emulated.
    

    Unsupported features such as pointers, classes, macros, direct GPIO, interrupts, and other libraries report an error. Axis.h is a virtual simulator API and needs a hardware implementation before use on a real robot.
