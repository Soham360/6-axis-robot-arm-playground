Take the controls.

Meet your robot.

Use await for each movement. Distances are meters, angles are degrees.

robot.moveJ([j1, …, j6], seconds)
Move all six joints smoothly within their limits.
robot.moveTo(x, y, z, seconds)
Position the tool using inverse kinematics. Y points up.
robot.grip() / robot.release()
Grab a nearby object or release the current payload.
robot.home() / robot.wait(seconds)
Return home or pause the program.
world.objects()
Get objects with id, shape, and position.
log(message)
Print a message to the console.

Programs run in an isolated worker. Stop terminates execution immediately. This is a kinematic playground; grasping uses proximity and released objects settle on the table.
